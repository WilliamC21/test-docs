# Trading Fees

Fees are set per account tier.

| Tier | Maker fee | Taker fee |
| ---- | --------- | --------- |
| 1    | 0.10%     | 0.20%     |
| 2    | 0.08%     | 0.15%     |
| 3    | 0.05%     | 0.10%     |

To change fees, open **Dashboard → Tiers** and edit the values.

See also: [Create a Market](create-a-market.md)
